<h2>🚀 Tecnologías Utilizadas</h2>

<p>
  ✔️ Arduino / ESP32 <br>

  ✔️ MQTT <br>
  ✔️ JSON <br>
  ✔️ Domótica IoT
</p>

<hr>

<h2>📌 Descripción</h2>

<p>
Este proyecto implementa un sistema de domótica capaz de:
</p>

<ul>
  <li>Monitorear dispositivos</li>
  <li>Enviar datos mediante MQTT</li>
  <li>Visualizar información en un dashboard</li>
  <li>Automatizar procesos del hogar</li>
</ul>
